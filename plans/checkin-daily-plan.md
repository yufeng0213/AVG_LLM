# 日历签到方案

## 概述

新建 `CheckInScreen.vue`，一个日历视图签到系统。用户点击当月日期签到，不同日期有不同奖励，月底完成全月签到有额外大奖。

## 日历视图

- 显示当月完整日历（7×N 网格）
- 已签到日期：打勾 + 显示获得物品图标
- 今日：高亮边框 + 可点击签到
- 未来日期：灰显不可点
- 上月未签日期：显示为空叉

## 奖励设计

### 每日基础奖励（固定）

```
每周循环模式：
周一 → 金币 (10~15)
周二 → 精力药水 ×1
周三 → 金币 (10~15) + 随机小礼物
周四 → 好感加速卡
周五 → 金币 (15~20) + 随机中礼物
周六 → 随机稀有道具
周日 → 金币 (20~30) + 周末礼包
```

### 周末特殊奖励池

**周六/周日额外掉落：**
| 道具 | 概率 | 说明 |
|------|------|------|
| 额外金币 5~20 | 40% | |
| 免入场券 | 15% | 小游戏免入场费 |
| 双倍金币卡 | 15% | 下局小游戏金币 ×2 |
| 主题碎片 ×1 | 10% | |
| 头像框体验卡 | 10% | 限时 3 天 |
| 限定头像框 | 5% | 永久 |
| 精力药水 ×3 | 5% | |

### 月度奖励

| 条件 | 奖励 |
|------|------|
| 全月签到（无断签） | 限定头像框 ×1 + 200 金币 |
| 签到率 ≥ 80% | 免入场券 ×2 + 50 金币 |
| 签到率 ≥ 50% | 主题碎片 ×3 |
| 签到率 < 50% | 无额外奖励 |

## 签到流程

```
选择月份 → 渲染日历
  → 高亮今日格子
  → 已签到日期显示已获得物品
  → 点击今日格子 → 显示今日奖励预览
  → 点击签到按钮 → 执行签到
    → 保存日期 + 获得物品
    → 播放获得动画
    → 更新日历显示
    → emit checkin-result 通知父组件
```

## 奖励预览

点击今日格子时，弹窗显示：

```
┌──────────────────────┐
│    4月14日 (周二)     │
│                      │
│  必得: 🧪 精力药水 ×1 │
│  惊喜: ???            │
│                      │
│     [ 签 到 ]        │
│                      │
└──────────────────────┘
```

签到后 "惊喜: ???" 变为实际物品图标。

## 月份切换

- 支持左右切换查看上月/下月
- 上月数据可查（只读，显示已签日期和获得物品）
- 下月显示为灰色预览（显示未来可获得的奖励类型）

## 签到动画

1. 点击签到 → 今日格子发光
2. 日历缩小淡出 0.2s
3. 奖励卡片从屏幕中央弹出，道具图标旋转进入
4. 惊喜道具翻转显示真容
5. 金币数字滚动累加
6. 日历恢复
