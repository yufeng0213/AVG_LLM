# 口琴 (Harmonica) 小游戏开发方案

## 概述

新建 `plugins/feature-dormitory/src/games/HarmonicaScreen.vue`，一个 10 孔 C 调复音口琴模拟器。

## 音频引擎设计

### 1. 振荡器组（每孔独立）
```
吹气口琴音色 = 
  [锯齿波 sawtooth @ 基频] × 0.35  → 簧片主振动
  [锯齿波 sawtooth @ 基频×1.003] × 0.12 → 轻微失谐，模拟双簧片
  [正弦波 sine @ 基频×2] × 0.08   → 高次泛音（金属感）
```

### 2. 带通滤波器（BiquadFilterNode）
- type: `bandpass`
- frequency: `基频 × 1.5`（保留簧片鼻音，去掉刺耳高频）
- Q: `3`（中等带宽）
- 增益: 高音孔(8+) 额外 -6dB 防刺耳

### 3. 颤音 LFO
- type: `sine`
- frequency: `5.5Hz`（模拟人吹气自然抖动）
- depth: `±3 cents`（调制到振荡器的 detune）
- gain: 柔和不夸张

### 4. 呼吸包络（GainNode）
- Attack: `60ms`（不是瞬态，是气流渐强的感觉）
- Sustain: `0.85`（持续吹气期间保持稳定音量）
- Release: `120ms`（松开后气流渐弱）

### 5. 和声共振（可选，增加共鸣腔感）
- ConvolverNode 或用长 reverb delay
- wet: `0.15`（少量混响模拟口腔共鸣）

### 交互
- **10 孔横排**，每个孔分上下两半：上半吹气，下半吸气
- **长按持续发声**（不像木琴一击即走，口琴是 sustained）
- **手指滑动**在孔之间移动时无缝切换音符
- 孔位按下时发光 + 缩放动画

### 颜色方案
- 吹气区: 暖金色调 `#ffd700 → #ff8c00`
- 吸气区: 冰蓝色调 `#60a5fa → #3b82f6`
- 口琴本体: 金属银灰 + 深色背景

## 模式

### 自由模式
- 无消耗，随便吹

### 跟吹挑战
- 系统演示一段旋律（亮灯提示孔位 + 吹/吸）
- 玩家复现
- 奖励 15+💰

## 和木琴的区别

| 特性 | 木琴 | 口琴 |
|------|------|------|
| 音符数 | 8 键 | 10 孔 × 2 = 20 音 |
| 发声方式 | 瞬态(percussive) | 持续(sustained) |
| 波形 | sine | sawtooth + 泛音 |
| 包络 | Attack 5ms + Decay 200ms | Attack 60ms + Sustain + Release 120ms |
| 颤音 | 无 | 5.5Hz LFO |
| 滤波 | 无 | bandpass Q=3 |
| 滑动 | 不支持 | 支持跨孔滑动 |
| 复用代码 | - | 复用 Toast / Challenge 框架 |
