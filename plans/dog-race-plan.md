# 赛小狗 方案

## 概述

在寝室侧边栏新增 🐕 赛狗按钮，点击后进入全屏赛狗页面。4 只小狗赛跑，赛前选择一只下注猜冠军，猜中赢金币。纯观赏型博彩小游戏。

## 核心玩法

### 投注系统

- **投注金额**：10/20/50/100 四档快捷金额
- **最低投注**：10 金币
- **动态赔率**：每只狗初始赔率不同，根据历史记录动态调整
  - 连胜的狗赔率降低（热门更便宜）
  - 连败的狗赔率升高（冷门赔率高）
  - 初始赔率范围：1.5x ~ 6.0x

### 四条跑道

4 只小狗，每只随机分配名字和颜色：

| 名字池 | 颜色池 |
|---|---|
| 小白、小黑、小黄、小花、小红、小灰、小棕、小橘 | 白色、黑色、黄色、花色、红色、灰色、棕色、橘色 |

每场比赛从名字池中随机选 4 个不重复的名字分配给 4 只狗。

### 跑姿系统（每局随机）

每场比赛开始时，每只狗随机分配一个跑姿（从跑姿池中抽取，可重复）：

| 跑姿 | 效果 |
|---|---|
| 匀速型 | 速度稳定，波动小 |
| 冲刺型 | 前期慢，后半程频繁加速 |
| 忽快忽慢型 | 速度大幅波动 |
| 爆发型 | 小概率大幅加速，其余时间偏慢 |
| 懒惰型 | 经常偷懒减速，但偶尔爆发 |
| 龟速型 | 整体偏慢但极少出错 |
| 神经质型 | 频繁打滑+频繁冲刺，极端波动 |

跑姿在每场比赛开始时随机分配，不可预测。

### 随机事件

比赛过程中每只狗可能触发的事件：

| 事件 | 效果 | 基础概率 |
|---|---|---|
| 🎲 打滑 | 暂停 0.5 秒 | 8% |
| ⚡ 冲刺 | 加速 1 秒 | 12% |
| 💤 偷懒 | 减速 1 秒 | 8% |
| 🌟 爆发 | 大幅加速 1.5 秒 | 3% |

具体概率受跑姿影响（如冲刺型的冲刺概率更高、懒惰型的偷懒概率更高）。

### 动画效果

1. **起跑动画**：倒计时 3-2-1-GO!，大字居中显示，然后小狗从起跑线出发
2. **跑步动画**：
   - 小狗用 CSS 动画"奔跑"（上下跳跃 + 左右摇摆）
   - 不同速度对应不同动画频率（快=频率高，慢=频率低）
   - 冲刺时放大 1.2 倍，打平时缩小 0.8 倍
3. **事件提示**：触发随机事件时在小狗上方弹出小气泡（⚡/💤/🎲/🌟）
4. **终点动画**：
   - 到达终点时放大跳跃庆祝
   - 冠军出现彩带效果（CSS 粒子）
   - 猜中时 Toast 金色提示
5. **跑道设计**：绿色草坪背景 + 白色虚线跑道 + 终点旗帜

### 趣味机制

- **每日免费观赛**：1 次免费（下注 0，赢了拿基础 50💰）
- **连胜奖励**：连续猜中 3 次，额外 +50% 奖金
- **连败保护**：连续猜错 5 次，下次赔率 ×2（安慰奖）
- **历史战绩**：显示每只狗最近 10 场胜率
- **狗语者成就**：累计猜中 20/50/100 次

### 经济平衡

- 期望值约 85%~95%（庄家优势 5%~15%）
- 赔率动态调整确保长期不亏不赚太离谱

## 技术实现

### 文件结构

```
plugins/feature-dormitory/src/
├── games/
│   ├── SlotMachineScreen.vue
│   ├── GachaScreen.vue
│   └── PachinkoScreen.vue
├── DogRaceScreen.vue         ← 新增
├── Toast.vue
├── FarmScreen.vue
├── DormitoryScreen.vue       ← 修改：加赛狗按钮 + 挂载
└── composables/
    └── useDormShop.js        ← 复用 economy/inventory 接口
```

### 技术要点

- Canvas 实现跑道和小狗渲染（比 CSS 更灵活）
- `requestAnimationFrame` 游戏循环，每只狗独立控制位置
- 跑道用 Canvas 绘制：绿色草坪背景 + 白色虚线 + 终点旗
- 小狗用 emoji 渲染（🐕）+ Canvas 变换实现动画效果
- 随机事件在每帧更新时按概率判定
- 比赛时长约 5~8 秒
- `localStorage` 持久化：`avg_llm_dog_race_state_v1`

### localStorage 存储结构

```javascript
{
  totalRaces: 0,
  totalWins: 0,
  totalEarned: 0,
  consecutiveWins: 0,
  consecutiveLosses: 0,
  dogRecords: {
    // 每只狗的历史胜率
    '小白': { wins: 5, races: 20 },
    // ...
  },
  lastFreeRaceDate: null,
  achievements: ['guess_20'],
}
```

### 通信模式

```javascript
// Props
const props = defineProps({
  coins: { type: Number, default: 0 },
})

// Emits
const emit = defineEmits(['back', 'dograce-result'])

// 比赛结果
emit('dograce-result', { cost, earned })
```

## 交互流程

```
[打开赛狗] → 看到跑道 + 赔率 + 投注区
    │
    ├─→ [选择投注金额] → 点击 10/20/50/100
    │
    ├─→ [选择小狗] → 点击某只狗高亮选中
    │
    ├─→ [开始比赛] → 倒计时 3-2-1-GO! → 比赛开始
    │
    ├─→ [观看比赛] → 小狗奔跑、随机事件触发、实时位置更新
    │
    └─→ [比赛结束] → 冠军揭晓 → 猜中/猜错 Toast 反馈
```
