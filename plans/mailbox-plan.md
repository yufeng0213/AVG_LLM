# 信箱方案

## 概述

寝室界面新增 📮 信箱按钮，用户给当前世界书的角色写信、贴邮票、投递。LLM 延迟 3~10 分钟回信，用户可在收件箱查看。

## 核心流程

```
用户点击 📮 → 信箱主页面
    → 选择写信 → 选角色 → 写内容(100~1000字) → 选邮票 → 投递
    → 保存 pending 队列，replyAt = now + random(3,10)min
    → 定时/唤醒时检查 pending → 调用 LLM 生成回信 → 存入 inbox
    → 用户看到未读红点，点击查看回信
```

## 延迟回信持久化

```js
// localStorage key: avg_llm_dormitory_mail_pending_v1
{
  [worldBookId]: [
    {
      id: "uuid",
      to: "小樱",
      content: "用户写的原文...",
      stamp: "star",
      sentAt: 1712185200000,
      replyAt: 1712186700000,  // sentAt + random(3~10min)
      replied: false,
    }
  ]
}
```

### 触发时机（三种）

1. **Electron 端**：`setInterval` 每 60 秒检查 pending 队列
2. **App 唤醒**：从后台切回 / 冷启动时检查
3. **用户打开信箱时**：也做一次检查

## 邮票系统

| 邮票 | 获取方式 | 效果 |
|------|---------|------|
| 🌸 普通邮票 | 初始 5 张 / 商店 10💰 | 普通回信 |
| 🌟 星光邮票 | 签到/游戏掉落 / 商店 50💰 | 回信更热情 |
| 🎀 蝴蝶结邮票 | 月度签到奖励 / 扭蛋稀有 | 回信附带好感度 +1 |
| 📮 限定邮票 | 扭蛋机 SSR 掉落 | 回信附带随机小礼物 |

## LLM 回信 Prompt

```
你是「{characterName}」，和送信人的好感度 {affection}（{stageLabel}）

角色设定：
{characterPersona}

最近的聊天记录：
{chatHistory}

你收到了对方的一封信：
"{letterContent}"

邮票类型：{stampBonus}

请以{characterName}的身份写一封回信。
要求：
1. 语气要符合角色性格和当前好感度阶段
2. 可以提到之前聊过的内容
3. 回信长度 50~200 字
4. 使用自然的书信语气，不要使用列表或格式化
5. 只输出回信正文，不要加标题或解释
```
