# 三消 (Match-3) 小游戏开发方案

## 概述

新建 `plugins/feature-dormitory/src/games/Match3Screen.vue`，一个 8×8 经典三消游戏。

## 核心玩法

- **8×8 网格**，6 种宝石
- 玩家**滑动交换**相邻宝石，形成 3+ 连线消除
- 消除后上方宝石下落，空位由新宝石填充
- 连锁反应持续直到无可消除
- **每局限 20 步**，达到目标分数即过关
- 每关目标递增，通关奖励金币

## 特殊宝石

### 4 连消除 → 行/列炸弹 💥
- 形成时该位置生成炸弹
- 与相邻宝石交换时清除整行或整列
- 计分：被炸宝石数 × 15

### 5 连消除 → 彩虹球 🌈
- 形成时该位置生成彩虹球
- 与任意宝石交换时，**消除场上所有同色宝石**
- 计分：消除宝石数 × 20

### 特殊+特殊交换
- 炸弹+炸弹 → 清除十字交叉区域（3×3）
- 炸弹+彩虹球 → 清除 3 行 + 3 列
- 彩虹球+彩虹球 → 清除全场

## 网格数据结构

```js
// grid[row][col] = { type: 0-5, special: null|'line'|'rainbow', id: unique }
grid = ref(Array.from({ length: 8 }, () => Array(8).fill(null)))
```

- type: 0~5 对应 6 种宝石
- special: null / 'line' (炸弹) / 'rainbow' (彩虹球)
- id: 唯一标识用于 Vue :key 动画

## 游戏流程

### 1. 初始化
- 随机填充 8×8 网格（预检无初始匹配）
- 如有初始匹配则重新生成

### 2. 玩家操作
- **pointerdown** 记录起始格
- **pointerup** 判断滑动方向 → 目标格
- 只允许相邻交换（上下左右）

### 3. 交换检测
```
交换两个格子 → 检查是否有匹配 → 有则执行消除链 → 无则交换回去
```

### 4. 消除链（核心循环）
```
检测所有匹配 → 标记消除 → 播放消除动画(200ms) → 
宝石下落(300ms) → 新宝石填充(200ms) → 
再次检测匹配 → 循环直到无可消除
```

### 5. 结算
- 每步结束后计算本步得分
- 连锁倍率：第 1 次消除 ×1, 第 2 次 ×1.5, 第 3 次 ×2, ...
- 更新总分 → 检查是否达标

## 动画设计（CSS）

| 动画 | 触发 | 效果 |
|------|------|------|
| swap-left/right/up/down | 交换 | translateX/Y 滑动 80px, 150ms |
| gem-pop | 消除 | scale(1) → scale(0) + opacity 0, 200ms |
| gem-fall | 下落 | translateY(-N * cellSize) → 0, 300ms |
| gem-enter | 新宝石入场 | scale(0) + translateY(-100px) → 正常, 200ms |
| line-clear | 炸弹引爆 | 行/列逐个闪烁消失, 50ms 间隔 |
| rainbow-burst | 彩虹球引爆 | 全屏同色宝石同时缩小 |
| screen-flash | 5 连/大招 | 全屏白闪 0.3s |
| combo-text | 连锁 | "2x Combo!" 浮出 + 放大 |

### 实现方式
- 动画由 JS 控制 class 添加/移除
- 使用 `setTimeout` 序列编排多阶段动画
- 动画期间锁定输入（`isProcessing = true`）

## 技术难点与解决方案

### 1. 滑动检测
- pointerdown 记录坐标 → pointerup 计算方向
- 滑动距离 < 20px 视为点击（忽略）
- 判断 dominant axis（x or y 差值更大的方向）

### 2. 匹配检测
```js
function findMatches(grid) {
  const matched = new Set()
  // 水平扫描
  for row in 0..7:
    for col in 0..5:
      if grid[row][col..col+2] 同色:
        matched.add(这三个坐标)
  // 垂直扫描同理
  return matched
}
```

### 3. 4连/5连检测
- 在 findMatches 中检查连续长度
- 长度 4 → 特殊宝石位置为中间两个之一
- 长度 5+ → 彩虹球

### 4. 防止死局
- 每次消除链结束后检查是否有可用交换
- 如无则自动重排（shuffle）

### 5. 初始无匹配
- 随机填充后运行 findMatches
- 如有匹配则重新生成直到无匹配
