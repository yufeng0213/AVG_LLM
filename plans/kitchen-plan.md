# 我的厨房 方案

## 概述

在寝室侧边栏新增 🍳 厨房按钮，进入全屏厨房页面（位于 `games/` 文件夹）。玩家从农场收获或菜市场购买原料，按照食谱组合烹饪出各种食品。烹饪过程有 timing 小游戏，做得越好品质越高。

## 烹饪小游戏（Timing 玩法）

- 点击"开始烹饪"后出现**圆形进度环**，中间有个**绿色目标区**
- 环顺时针转动，指针扫过绿色区域时点击"完成"
- 判定结果：
  - 🌟 **完美**（正中间）→ ★★★★★ 售价 ×2
  - ✨ **优秀**（绿色区内）→ ★★★★☆ 售价 ×1.5
  - 👍 **普通**（绿色区外但环内）→ ★★★☆☆ 售价 ×1
  - 😢 **失败**（没点上）→ ★☆☆☆☆ 售价 ×0.5
- 不同难度菜品：
  - 简单菜品（2~3原料）：绿色区域大，转动慢
  - 困难菜品（4~5原料）：绿色区域小，转动快

## 趣味机制

- **连续成功**：连续 3 次完美/优秀 → "厨神模式"，下一道菜额外 +30% 售价
- **食谱图鉴**：每道菜第一次做出来时高亮显示"新发现！"
- **全图鉴成就**：收集全部 24 道菜 → "料理大师"称号
- **随机暴击**：5% 概率做出"传说级料理"，售价 ×5
- **每日特价菜**：每天随机一道菜品售价额外 +50%

## 经济平衡

- 原料成本：约 15~40💰 每道菜
- 普通售价：约 30~120💰
- 利润率约 100%~200%
- timing 失败只有 0.5 倍可能亏本
- 熟练后平均利润率约 150%

### 技术要点

- 纯 Vue + CSS 实现，不需要 Canvas
- 食谱网格：CSS grid 布局，分类 tab 切换
- 烹饪圆环：CSS `conic-gradient` + `@keyframes` 旋转动画
- 判定逻辑：根据当前旋转角度计算是否在目标区域内
- 原料库存：读取 `props.inventory` 中的农场作物 + 菜市场原料
- 菜市场：弹出面板购买原料，金币从 economy 扣除
- `localStorage` 持久化：`avg_llm_kitchen_state_v1`
  - 已解锁菜谱列表（首次发现记录）
  - 烹饪统计（总次数、连胜、传说次数等）
  - 成就列表
  - 每日特价菜日期

## 交互流程

```
[打开厨房] → 看到食谱网格 + 图鉴进度
    │
    ├─→ [选择分类] → 点击饮品/面点/菜/甜品标签
    │
    ├─→ [选择食谱] → 点击某道菜 → 显示配方详情 + 原料检查
    │
    ├─→ [菜市场] → 缺少原料 → 点击菜市场购买
    │
    ├─→ [开始烹饪] → Timing 圆环小游戏
    │
```
