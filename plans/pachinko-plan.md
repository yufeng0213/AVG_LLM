# 弹珠机方案

## 概述

在寝室屏幕侧边栏新增 🎯 弹珠机按钮，点击进入独立全屏页面。弹珠从顶部释放，经过钉子弹跳后落入底部格子获得奖励。

## 核心玩法

- **发射消耗**: 20金币 / 双倍模式40金币（奖励×2）
- 拖拽发射器控制力度和角度
- 底部9格奖励：|10|5|20|50|100|50|20|5|10|
- 中间100金币格子最窄难中，两侧较宽易中

## 趣味机制

- 10%概率金色弹珠（奖励×3）
- 连续3次落入中间3格，下次中间格子变宽
- 弹珠碰钉子发光特效
- 落入100格全屏金色闪光

## 物理实现

- Canvas + requestAnimationFrame 游戏循环
- 手写重力 + 弹性碰撞（无需物理引擎）
- gravity: 0.4, bounceFactor: 0.7, randomness: 1.0
