# 七日连续签到方案

## 概述

新建 `CheckInScreen.vue`（七日模式），每日签到掉落金币和道具，连续签到奖励递增，断签重置。

## 核心规则

- 每日只能签到一次，跨天自动刷新
- 连续签到第 N 天奖励递增，断签从第 1 天重新开始
- 无补签功能

## 签到动画

1. 点击签到 → 礼盒弹跳 + 发光
2. 翻开 → 物品图标从卡片中飞出，旋转放大到屏幕中央
3. 结果展示 → 物品名称 + 数量 + 获得音效（Web Audio）
4. 金币自动累加 → 数字滚动效果

## 签到流程

```
点击签到 → 检查今日是否已签到 → 否
  → 更新 streakDays（与昨天连续则+1，否则重置为1）
  → 根据 streak 确定奖池（铜/银/金）
  → 随机抽取 1~2 个道具
  → 保存到 localStorage
  → 播放获得动画
  → emit checkin-result 通知父组件加金币
```

## 与其他系统联动

- **免入场券** → 进入小游戏时检测，有券则扣除 1 张并跳过扣费
- **双倍金币卡** → 进入小游戏时检测，使用后下局金币翻倍
- **好感加速卡** → 在送礼流程中应用倍率
- **精力药水** → 直接修改 dormitory 的 energy 状态
- **主题碎片** → 达到 10 个时提示可兑换
